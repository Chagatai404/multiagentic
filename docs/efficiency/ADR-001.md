# ADR-001: E0/E1 evidence and conservative resource control

Status: accepted implementation scope, 2026-10-26. Base: `e7a2c5b`.

Current M5 reports invocation records, native usage coverage and explicit pricing
estimates; M6 supplies isolated dependency plans and verified serialized integration.
Neither measures subscription credits, internal provider turns, or live-model savings.
The existing benchmark is scripted and has unknown token/cost values. These contracts
are the baseline, rather than assumptions to replace.

Implement E0 reporting and E1 additive budget controls as one resumable milestone.
Retain selected/requested identity separately from any verifiable actual identity.
Version report schemas and label reported, measured, estimated and unavailable data.
Keep absent values null; only explicit user pricing rules may produce dollar estimates.

Add named optional node budget overrides, preserving existing `node_budgets` defaults.
Resolve effective budgets when creating tasks and persist them for continuation.
Default new plans to concurrency one while keeping explicit concurrency up to three.
Reported limits remain pre-next-call stops: in-flight consumption can overshoot.

For finite reported limits, serialize admission unless a defensible configured allowance
can be reserved. Do not invent a forecast from missing or fake usage. Persist any
reservation before launch; settle only with complete usage, and retain unknown/crashed
outcomes as inspection blockers. Cross-process admission and recovery require tests.
Configured allowance is never described as remaining account balance or credits.

Do not change completion, independent review, human approval, ownership, protected-path,
verification-digest, unknown-outcome or manual promotion gates. Model calls stay behind
existing providers. No paid calibration is authorized by this ADR. E2–E5 (context/plan
reuse, automatic routing, new repair policies and operating presets) remain later work
unless separately implemented and verified.

Regression tests precede behavior changes. Benchmark identical seeded fixtures across
arms, including failing checks, disjoint work and high-risk approval stops. Report raw
outcomes and local timing with null fake usage, plus an owner-opt-in live protocol.
Offline evidence supports orchestration claims only; successful live editing, actual
model quality and paid savings require separate measurements.
